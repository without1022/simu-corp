# Contribution Guide

Thank you for your interest in SimuCorp! We welcome contributions of all kinds — code, documentation, design, and ideas.

## How to Get Involved

### 📝 Report Issues

- Use GitHub Issues to submit bugs or feature suggestions
- Include a clear title and description
- For bugs, please include reproduction steps

### 🔧 Submit Code

1. Fork this repository
2. Create a new branch: `git checkout -b feature/your-feature`
3. Commit changes: `git commit -m "feat: add your feature"`
4. Push to the branch: `git push origin feature/your-feature`
5. Submit a Pull Request

### Development Standards

- Read [DEVELOPMENT.md](development/DEVELOPMENT.md) for Agent collaboration guidelines
- Maintain consistent code style
- New features should include tests
- Keep documentation in sync

### Documentation Contributions

If you're skilled in writing or translation, you're welcome to:

- Improve existing design documents
- Add tutorials and use cases
- Translate into other languages

### Discussion & Communication

- Use GitHub Discussions for architecture design
- Track development tasks via Issues

## Code of Conduct

Please maintain friendly, respectful, and constructive communication. See [CODE_OF_CONDUCT](CODE_OF_CONDUCT.md) for details.
