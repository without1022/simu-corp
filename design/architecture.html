SimuCorp Architecture

Self-Evolving Multi-Agent Collaboration System — Layered Architecture

4-Layer Architecture

  • • Presentation: React SPA, 6 pages
  • • Gateway: OpenClaw, WS+REST
  • • Agent: EA/HR/GTF + Dept Pool
  • • Infrastructure: PG + Redis + MCP

Self-Evolution Loop

  • • CEO → EA → GTF execution
  • • GTF detects skill gaps
  • • HR recruits & evaluates
  • • Agent promoted to Dept

Key Decisions

  • • L0-L3 approval hierarchy
  • • Event-driven via message bus
  • • Unified MCP tool interface
  • • Branch offices for scale
