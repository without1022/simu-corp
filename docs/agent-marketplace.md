## 1. 设计目标

Agent 市场是模拟公司 (SimuCorp) 生态的“公共人才市场”。它依托于 GitHub 开源仓库，将 Agent 模板的流通从单一实例内部扩展至全球社区，实现：

- **开放共享**：任何模拟公司实例均可上传其培养并验证过的 Agent 模板，供其他实例下载使用。
- **降低冷启动成本**：新用户部署后，其 HR Manager 可直接从市场搜索、下载高质量模板，无需从零进行岗位调研与 Soul 编写。
- **安全可控**：所有上传模板必须通过自动 AI 安全审核，支持带/不带通用记忆两种版本，严防敏感信息泄漏。
- **优胜劣汰**：通过评分、下载量、官方认证、使用成功率构建多维评价体系，让优质模板自然浮现。
- **公告墙引导**：市场维护公告墙，HR 检索时优先展示公告推荐内容，并定期发布“人才缺口”以引导社区贡献。
- **生态健康可观测**：市场公开健康度指标，便于社区与维护者及早发现审核积压、质量滑坡等问题。

## 2. 核心概念

### 2.1 市场流通物：Agent 模板包

市场上流通的是 **Agent 模板包**，而非运行中的 Agent 实例。模板包包含完整的岗位定义与可选通用知识，下载后可在本地立即实例化为实习 Agent。

**模板包结构**：

```json
{
  "package_id": "pkg-xxxx",
  "template": {
    "name": "iOS开发工程师",
    "role": "iOS Developer",
    "description": "负责iOS应用的设计、开发和维护",
    "prompt_template": "完整的Soul文本（Markdown格式）...",
    "suggested_runtime": "claude-code",
    "suggested_primary_model": "claude-sonnet-4",
    "suggested_fallbacks": ["deepseek-coder", "qwen-plus"],
    "suggested_tools": ["xcode-mcp", "github-mcp", "apple-docs-mcp"],
    "capabilities": {
      "skills": ["Swift", "SwiftUI", "UIKit", "CoreData"],
      "domain": ["mobile", "ios"],
      "level": "mid"
    },
    "internship_kpi": {
      "task_count": 10,
      "duration_days": 7,
      "pass_threshold": 80
    },
    "dependencies": {
      "mcp_servers": ["xcode-mcp", "github-mcp"],
      "min_simu_corp_version": "1.2.0"
    }
  },
  "general_memory": {
    "included": true,
    "description": "包含iOS开发通用知识：UIKit最佳实践、SwiftUI常见模式",
    "memory_items": [
      {
        "type": "knowledge",
        "content": "在UIKit中，使用dequeueReusableCell...",
        "tags": ["UIKit", "performance"]
      }
    ]
  },
  "market_metadata": {
    "publisher": "simucorp-instance-abc",
    "publisher_name": "某科技公司模拟公司实例",
    "version": "1.2.0",
    "min_simu_corp_version": "1.2.0",
    "created_at": "2026-07-01T00:00:00Z",
    "updated_at": "2026-07-15T00:00:00Z",
    "provenance": {
      "source_agent_id": "ios_dev_01",
      "original_hr": "hr_manager",
      "total_tasks_completed": 150,
      "success_rate": 0.94,
      "average_quality_score": 4.3
    }
  },
  "market_stats": {
    "downloads": 42,
    "rating": 4.5,
    "reviews_count": 12,
    "verified": true,
    "last_downloaded": "2026-07-20T00:00:00Z"
  }
}
```

**关键字段说明**：
- `dependencies`：声明必需的 MCP Server 和最低模拟公司版本，供下载时自动检查。
- `general_memory`：可选，上传者需明确是否包含通用知识记忆。

### 2.2 通用记忆选项

上传者在上传模板时必须选择记忆级别：

| 选项 | 说明 | 安全性 | 审核要求 |
|------|------|--------|----------|
| **不带记忆** | 仅上传 Soul 与配置 | 最高 | 常规自动审核 |
| **附带通用知识记忆** | 上传 Soul + 通用领域知识（技术最佳实践、行业常识等） | 中 | 需通过 AI 深度安全扫描，确认无敏感信息 |
| **附带完整通用记忆** | 上传 Soul + 完整的非私密记忆（需严格审核） | 较低 | 需额外人工复核 |

**安全红线（一票否决）**：
- 绝对禁止包含：个人身份信息、API Key、密码、内网地址、用户数据、商业机密。
- AI 审核将自动扫描并拒绝含以上内容的包。
- 上传者必须勾选“我已确认此模板不包含任何敏感信息”。

## 3. 市场架构

市场作为中心化仓库，依托 GitHub 开源项目运行，提供 Web API 供模拟公司实例交互。

```
github.com/simu-corp/marketplace
├── templates/                  # 模板包存储
│   └── pkg-xxxx/
│       ├── template.json       # 完整模板定义
│       ├── soul.md             # Soul 独立文件
│       └── memory/             # 可选通用记忆
├── reviews/                    # 用户评价数据
├── verified/                   # 官方认证列表
├── bulletin-board.json         # 公告墙内容
├── stats.json                  # 市场统计
└── health.json                 # 市场健康度指标
```

模拟公司实例通过市场 API 进行上传、搜索、下载等操作，所有写操作最终通过 PR 或经认证的 API 提交至仓库。

## 4. 上传与发布流程

### 4.1 上传前置条件

实例上传模板需满足以下任一条件：
- 该模板已在本地使用，且其招聘的 Agent 转正成功率 ≥ 70%。
- 该模板对应的 Agent 已完成 ≥ 50 个任务且成功率 ≥ 85%。
- 该模板已通过 CEO 手动标记为“可发布”。

### 4.2 上传步骤

1. **选择模板**：HR Manager 或 CEO 从本地模板库选择。
2. **选择记忆选项**：确定是否附带通用记忆及级别。
3. **自动生成包**：系统提取 Soul、配置、来源数据并匿名化。
4. **本地预检**：
   - 正则匹配 + LLM 扫描敏感信息。
   - 检查 Soul 完整性（8 个标准章节）。
5. **提交市场**：通过 API 或创建 PR。
6. **AI 审核（市场侧）**：
   - 安全扫描（敏感信息检测）。
   - Soul 质量评分（参照《Prompt 工程指南》）。
   - 结构完整性校验。
   - 通用记忆深度审查（若附带）。
7. **审核结果**：
   - **通过** → 发布，进入“最新上架”列表。
   - **需修改** → 返回具体修改建议。
   - **拒绝** → 说明原因（尤其安全问题）。

### 4.3 AI 审核标准

| 审核项 | 要求 | 权重 |
|--------|------|------|
| 安全性 | 无任何敏感信息（一票否决） | 必须 |
| Soul 完整性 | 包含 8 个标准章节 | 必须 |
| Soul 质量 | 按《Prompt 工程指南》评分 ≥ 7.0 | 0.4 |
| 结构规范 | 符合模板包标准结构 | 0.3 |
| 来源可信度 | 上传者历史信誉、实例运行时长 | 0.2 |
| 文档质量 | 描述清晰、标签准确 | 0.1 |
| **综合通过线** | ≥ 6.0 通过，< 6.0 返回修改 | — |

首次上传或信誉较低的上传者，其模板可能被送入人工复核队列。

## 5. 检索与下载

### 5.1 HR Manager 检索策略（更新）

HR Manager 收到 `TALENT_REQUEST` 后的搜索逻辑已升级：

1. **检查公告墙**：公告墙中是否有匹配的推荐模板？若有，标注“市场公告推荐”并置顶。
2. **并行搜索**：同时搜索内部模板库和外部市场。
3. **合并排序**：综合得分 = 官方认证(0.25) + 评分(0.20) + 下载量(0.15) + 匹配度(0.25) + 本地优先加成(0.15)。
4. **返回 Top 5** 推荐，并明确标识每个模板的来源（内部/市场）及公告推荐标签。

**本地优先加成**：内部模板在合并排序时获得 0.15 的额外权重，以优先使用已验证的组织资产。

### 5.2 搜索 API

`GET https://marketplace.simu-corp.org/api/v1/templates/search`

**参数**：

| 参数 | 说明 |
|------|------|
| `skills` | 技能关键词，逗号分隔 |
| `domain` | 领域过滤 |
| `runtime` | 基座类型 |
| `verified_only` | 仅官方认证 |
| `min_rating` | 最低评分 |
| `min_compatibility` | 最低兼容版本（如 `1.0.0`） |
| `sort_by` | `rating` / `downloads` / `newest` |
| `page`, `page_size` | 分页 |

响应中包含每个模板的兼容性信息（`min_simu_corp_version`）和依赖列表，便于 HR Manager 进行本地检查。

### 5.3 下载与实例化

```bash
# HR Manager 下载模板包
simu-corp marketplace download pkg-xxxx

# 实例化为实习 Agent（自动检查依赖和兼容性）
simu-corp agent create --from-marketplace pkg-xxxx --department rd
```

**依赖与兼容性自动检查**：
- 若模板声明了 `mcp_servers` 依赖，检查本地是否已安装这些 MCP Server；若缺失，提示“此模板需要以下 MCP Server：xcode-mcp。是否自动安装？”
- 若模板声明了 `min_simu_corp_version`，且当前实例版本低于要求，提示“模板要求模拟公司 v1.2.0，当前版本 v1.0.0，请升级后重试。”

## 6. 评价体系与市场健康

### 6.1 多维评价

| 维度 | 说明 |
|------|------|
| **评分 (1-5星)** | 下载使用后的综合评价 |
| **下载量** | 总下载次数、近期趋势 |
| **官方认证** | 经官方额外审核，标记为“已验证” |
| **使用成功率** | 下载者反馈的基于该模板的 Agent 转正成功率（可选上报） |
| **文字评论** | 详细使用体验、改进建议 |

**市场排名算法**：
```
排名分 = 官方认证权重(×1.5) × [评分×0.4 + log(下载量)×0.2 + 使用成功率×0.3 + 近期活跃度×0.1]
```

### 6.2 市场健康度指标

市场维护者与社区可通过 `health.json` 监控市场运行状况：

| 指标 | 说明 |
|------|------|
| 审核队列长度 | 待审核模板数量 |
| 本周通过率 | 审核通过数/提交数 |
| 活跃上传者数量 | 近30天有上传的用户数 |
| 模板平均质量趋势 | 近30天新上架模板的平均评分 |
| 社区互动率 | 近30天新增评价数/下载量 |

当审核队列积压超过 20 个待审模板，或周通过率低于 60%，维护者需介入处理。

## 7. 公告墙与人才缺口

### 7.1 公告墙

市场首页设置公告墙，展示：
- **官方推荐**：经官方精选的高质量模板。
- **热门趋势**：近期下载量飙升的模板。
- **新星推荐**：上架不久但评分突出的新模板。
- **安全公告**：已发现问题的模板下架通知及替代建议。
- **生态需求（招募令）**：由市场分析生成的“人才缺口”呼吁。

**HR 检索优先级**：
HR Manager 搜索时，若公告中有匹配的推荐，该模板将被置顶并标注“📢 公告推荐”。

### 7.2 人才缺口分析

市场定期（每两周）通过分析搜索日志、下载数据与招聘失败记录，自动生成“人才缺口报告”，并在公告墙发布“招募令”：
> “近30天，数据分析类模板搜索量增长 200%，但市场上仅 3 个相关模板，其中仅 1 个评分 ≥ 4.0。社区贡献者可优先开发此类模板。”

该机制引导社区补充稀缺的高质量模板，形成供需平衡。

## 8. 模板更新与关注机制

### 8.1 模板关注

用户可在市场中对模板点击“关注”。当模板发布新版本时，所有关注者将收到通知（在模拟公司实例的 Dashboard 中显示）。

### 8.2 版本更新与本地同步

- 上传者发布新版本时，需遵循语义化版本，并附更新日志。
- 关注了该模板的 HR Manager 可在 Dashboard 看到更新提示：“您关注的模板 `iOS开发工程师` 发布了 v1.3.0。”
- HR Manager 可评估后决定是否更新本地的 Agent Soul（例如，当原 Agent 绩效下滑时）。

## 9. 安全与治理

### 9.1 上传者信誉系统

| 指标 | 说明 |
|------|------|
| 上传模板总数 | 累计 |
| 模板平均评分 | 所有模板评分的均值 |
| 被下架次数 | 累计违规或质量问题下架 |
| 官方认证数量 | 获得认证的模板数 |

高信誉上传者的模板在搜索排名中获得小幅加成；被下架超过 3 次后，其后续提交需强制人工审核。

### 9.2 举报与下架

- 任何用户可举报模板（安全问题、质量严重不符、抄袭）。
- 经审核确认后：
  - 安全问题：**立即下架**，通知所有下载过该模板的用户（通过 Dashboard 告警）。
  - 质量问题：标记“需优化”，降低搜索排名。
  - 抄袭：下架并警告上传者。

所有下架操作记录在 `health.json` 的安全日志中。

## 10. 市场页面设计（前端新增）

### 10.1 路由

- `/marketplace` — 市场首页（公告墙 + 推荐模板 + 统计）
- `/marketplace/search` — 高级搜索
- `/marketplace/:pkgId` — 模板详情
- `/marketplace/upload` — 上传模板

### 10.2 首页布局（概要）

顶部公告墙（滚动展示），随后是市场统计卡片（模板总数、本周新增、认证数量、活跃上传者）。下方为“本周热门模板”卡片网格，以及“我的上传”区域和“市场健康度”简要面板。

### 10.3 模板详情页

展示模板评分、下载量、认证标识、上传者信息、模板核心属性（角色、基座、技能等）、Soul 预览（只读，可展开）、依赖信息（MCP Server 要求、最低版本）、记忆选项说明。下方有用户评价列表，以及“下载模板”、“实例化 Agent”、“关注”和“举报”按钮。
